## RECOMMENDED DATA DOWNLOAD ORDER

1. START HERE (Free, No Request Needed):
   - Statistics Canada Tables 38-10-0158-01, 38-10-0022-01 (direct export)
   - CMHC Housing Market Outlook reports (download PDF)
   - CMHC Rental Market Report for KCW CMA (download Excel)
   - Canadian City Parks Report for Kitchener (download PDF)
   - Infrastructure Canada news releases (save web pages)

2. THEN REQUEST (Email/Portal, Usually Free):
   - Statistics Canada custom tabulation (Tables by municipality)
   - CMHC individual municipal housing data (if available)
   - Infrastructure Canada project list and outcomes
   - Park People custom city reports (Cambridge, Waterloo)

3. FOLLOW UP (Phone/Email, Local Governments):
   - Region of Waterloo: parks inventory, capital budgets
   - Cities and townships: parks master plans, public space strategies
   - County planning: development patterns, housing data

4. SYNTHESIZE (Internal Analysis):
   - Compile all data into master spreadsheet
   - Create comparison tables
   - Map metrics to placemaking framework
   - Document gaps and limitations
